# Particle-1 release 0.2.0 regression check

**Regression check: passed. Production-readiness gate: failed; text-to-SQL remains beta.**

The 0.2.0 minor release was evaluated after the grounding citation ownership fix.
Issue #80 recorded the budget and acceptance criteria before any paid request.
The candidate is commit `e097fc27e76dc0738f4bdf6674429fa25b71c03c`, with app version
0.2.0 and build 3. The full run is `E5E37B55-39D0-44A4-B1C0-AD0FDC5C3C77`.
It ran once; no completed gate was repeated to improve its score.

The comparator is the [original Particle-1 baseline](../../Evals/baselines/text-to-sql-v1-cloud-particle-1-baseline.md),
run `223385F4-C939-4BD0-88A2-97AC0CAC3133` at commit `98e1778`.
The [current gate](0.2.0.md) and [triage](0.2.0-triage.md) contain the sanitized
release evidence. Raw prompts, generated SQL, result rows, and credentials are excluded.

## Probe, smoke, and cost

The provider probe passed all eight requests without warnings. The advertised
context window (1,048,576 tokens), output limit (131,072 tokens), tool support,
and supported reasoning efforts match the app's profile. No earlier standalone
probe artifact was available in this checkout for a complete historical comparison.

The smoke run completed all 15 results with matching model identities, no
timeouts, and 15/15 transport success. Static results were 13 passed, one wrong
decision, and one parse failure; these were recorded without rerunning them.
None of the pre-registered smoke stop conditions was triggered.

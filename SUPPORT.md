# Support

Widen is an open-source project, not a commercial support product.

## Where To Ask

- Use GitHub Issues for reproducible bugs, build failures, and focused feature
  requests.
- Use a feature request only after checking the README and existing issues.
- Do not use public issues for secrets, private schemas, production query
  results, or vulnerability details. See [SECURITY.md](SECURITY.md).

## Useful Bug Report Details

- Widen version or commit.
- macOS version and Mac model.
- Xcode version if building from source.
- Whether you are using local AI, cloud AI, or manual SQL only.
- PostgreSQL version and whether the server is local or remote.
- Exact steps to reproduce.
- Sanitized error text, logs, screenshots, schema snippets, or SQL.

## Maintainer Scope

Maintainers can help with Widen bugs and documented development workflows. They
cannot debug private databases, provide database administration support, or
recover local Keychain items.

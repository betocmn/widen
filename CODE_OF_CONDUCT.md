# Code Of Conduct

Widen should be a practical, respectful place to improve a developer tool.

## Expected Behavior

- Be direct, specific, and kind.
- Assume reports are made in good faith, then verify with evidence.
- Critique ideas and code, not people.
- Keep discussions relevant to the project.
- Respect privacy; do not post someone else's private data, credentials,
  schemas, logs, screenshots, or contact details.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Discriminatory language or conduct.
- Sexualized comments or imagery.
- Publishing private information without permission.
- Repeated off-topic, inflammatory, or bad-faith participation.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; reject
contributions; or block participants when needed to keep the project usable and
safe.

If you need to report conduct privately, use the maintainer contact path listed
on the repository owner's GitHub profile.
